# EatAndChill

EatAndChill — десктопний застосунок для управління рестораном, створений за допомогою Qt 6 та SQLite.

## Можливості
- меню з категоріями
- відображення фотографій страв
- кошик замовлень
- історія замовлень
- стоп-лист
- пошук і сортування
- робота з базою даних SQLite

## Використані технології
- C++
- Qt 6
- SQLite
- CMake

## Запуск проєкту
1. Відкрити проєкт у Qt Creator
2. Відкрити файл `CMakeLists.txt`
3. Запустити CMake
4. Зібрати проєкт
5. Запустити застосунок
